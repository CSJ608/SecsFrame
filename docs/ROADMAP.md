当前报告、报警通知和远程命令切片使用可替换工程 profile、动态
<code>SecsItem</code> 标识，并保留报警与命令结果原始代码，不宣称已经
核对 E30 的生命周期、代码语义或应答枚举。报警目录查询同样是非规范性
工程基线；单报警发送启停也使用显式可替换控制码。在线转换策略默认不注册，
保持既有宽松接受行为。通讯建立策略在 Host 与 Equipment 两侧同样默认
不注册；拒绝不改变既有通讯状态或对端身份，恢复由应用在同一 Selected
会话显式重试，库不启动后台循环。远程命令接受策略也默认不注册；应用可
依据当前通讯/在线状态决定是否执行命令，库不内置未经 E30 核对的状态矩阵。
Collection Event 发送策略沿用相同的默认不注册模式；拒绝发生在动态值
采集和 S6F11 事务之前，应用改变决策后可在同一会话显式重试。
报警通知发送策略同样默认不注册；已注册报警的发送启停检查优先，策略拒绝
发生在 S5F1 事务之前，并可在同一会话显式重试。至此当前 Equipment 主动
业务发送入口的应用状态策略已经闭环。

报警历史/批量控制仍是标准核对后的优先项：最小切片必须先用授权 E30-0526
核对消息条件、数据结构和代码语义，再确定可替换 profile 下的不可变历史
模型、Equipment 快照边界、Host 查询 API、严格向量和真实 TCP 证据；核对
完成前不固化新的默认消息对。

当前仓库没有可用于该核对的授权材料，因此先完成不新增消息映射的 Equipment
运行期命令目录和逐项本地可用性：动态标识精确处理器优先，现有单一处理器
作为全局回退；已匹配但禁用的精确项保持失败结果且不进入接受策略或回退，
应用重新启用后可在同一 Selected 会话显式重试。

命令权限/参数约束的评估结论是暂不增加第二套通用策略：现有全局接受策略
已经覆盖通讯/在线状态等应用决策，精确处理器可以校验命令专属参数并返回
原始整体/参数结果码。完整角色权限、参数 Schema 与调度仍是后续能力。

断线恢复现提供 Host/Equipment 对称的显式单次入口：每次调用等待当前或
下一次 Selected 后只发起一次既有通讯建立事务；取消不会在重选后迟到执行，
拒绝或失败不自动重试，成功也不隐式恢复在线状态。应用仍拥有重试与并发
串行化决策，库不引入后台循环或未经 E30 核对的状态矩阵。

阶段 2 其余报警历史/批量控制和完整命令权限/调度都需要先取得授权
E30-0526 材料。下一可执行优先级已转入阶段 3；SML 调试读写已经基于许可
清晰的公开实现完成非规范性 profile，为现有动态 <code>SecsMessage</code>
和全部 <code>SecsItem</code> 类型提供确定性文本写出、严格读取、资源边界与
自主协议向量，不宣称标准 SML 合规。已在该稳定文本表示上增加已解码数据
消息的版本化 Trace 导出、结构化脱敏与显式 allowlist 受控重放；重放通过
公共发送 API 创建新事务，不复用旧会话或 System Bytes。可选时序重放也已
完成：只使用允许发送记录的相邻时间戳，支持显式加速和缩放后单次等待封顶，
默认重放仍不等待。结构化 HSMS 诊断现可通过独立受限信封导出；快照只包含
稳定标量，明确排除异常和原始帧。现有公共未认领控制事件也可导出不含 Body
的十字节头元数据，同时保持未知非零 SType 的原始值。

## 阶段 3：元数据与工具

- [x] SML 调试读写。
- E173 SMN 日志与消息文档。
- E172 SEDD 设备字典导入、校验与发现。
- [x] 已解码数据消息的 Trace 导出、结构化脱敏和受控重放基线。
- [x] 显式启用、可缩放且单次等待封顶的 Trace 重放时序。
- [x] 不包含异常与原始帧的受限结构化诊断 Trace 导出和严格读取。
- [x] 公共未认领控制消息的受限头元数据 Trace 导出和严格读取。
- [x] 默认关闭、不含 Body/原始字节的完整控制面头元数据观测。
- [x] 显式分级、默认不导出 Body 的数据消息解码失败样本。
- [x] 默认关闭、有界且显式分级的四类运输故障前缀快照诊断。
- 其他运输层互操作诊断扩展。

当前 Trace 基线不接管连接事件流，也不把原始标识写回线上。时序重放默认
关闭，并继续经过显式 allowlist 与公共发送 API。诊断快照始终排除
<code>Error</code> 与 <code>Frame</code>。完整控制元数据观测必须在连接
选项中显式启用，覆盖内部握手但只复制方向、actor 状态和十字节头，不含
Body、原始线上字节、transport generation 或时间戳。后续故障原始样本
已先覆盖公共事件中忠实保留的完整 data frame：捕获分为 MetadataOnly、
RedactedPayload 与 RawPayload，payload codec 默认关闭，声明脱敏范围必须
全为零且可严格复核。它不包含 TCP 长度前缀或分片，也不能进入重放。
运输故障现通过默认关闭的独立流与 StreamFrame 2.6.0 报告的原始 transport
Session ID 关联；四种错误都保留实际字节数与截断状态，队列容量有界、满时
丢弃最旧项。SecsFrame 统一最多保留 8 KiB 前缀，再按 MetadataOnly、
RedactedPayload 或 RawPayload 捕获，payload codec 默认关闭。该前缀可能含
四字节长度头，不能进入重放；Trace v2 明确记录 Complete/Truncated，并拒绝
缺少完整性字段的 v1。
E173 SMN 与 E172 SEDD 仍需先核对授权标准及允许分发的 Schema/表示形式。
