- [x] Host、Equipment 双角色端点及两种 Active/Passive 拓扑的双向回环。

## 阶段 2：GEM 通用能力

- [x] 独立 <code>SecsFrame.Gem</code> 程序集与可替换消息 profile。
- [x] 通讯建立、在线/离线状态、动态变量读取、设备常量和应用托管时钟。
- [x] 面向 Host 与 Equipment 的独立基础能力 API 和真实 TCP 垂直测试。
- [x] 报告定义、事件链接和 Collection Event。
- [x] 报警通知的动态标识、代码透传、Host 处理器和 Equipment 发送链路。
- [x] 远程命令的动态参数/结果、Host 发送和 Equipment 处理链路。
- [x] Equipment 运行期报警目录注册与 Host 全量/按标识查询。
- [x] 单个已注册报警的发送启停、未知标识拒绝和通知发送门控。
- [x] Equipment 在线/离线转换的应用决策、显式拒绝与状态保持。
- [x] Host/Equipment 双向通讯建立应用决策、显式拒绝与同会话重试恢复。
- [x] Equipment 入站远程命令的应用状态接受策略、拒绝短路与同会话重试。
- [ ] Collection Event、报警通知等其余业务消息的应用状态门控。
- [ ] 报警历史/批量控制、命令目录/权限/调度和更完整的状态/错误恢复。
- [ ] 使用授权 E30-0526 核对基础消息条件、数据项、应答值和状态转换。

当前报告、报警通知和远程命令切片使用可替换工程 profile、动态
<code>SecsItem</code> 标识，并保留报警与命令结果原始代码，不宣称已经
核对 E30 的生命周期、代码语义或应答枚举。报警目录查询同样是非规范性
工程基线；单报警发送启停也使用显式可替换控制码。在线转换策略默认不注册，
保持既有宽松接受行为。通讯建立策略在 Host 与 Equipment 两侧同样默认
不注册；拒绝不改变既有通讯状态或对端身份，恢复由应用在同一 Selected
会话显式重试，库不启动后台循环。远程命令接受策略也默认不注册；应用可
依据当前通讯/在线状态决定是否执行命令，库不内置未经 E30 核对的状态矩阵。
下一优先级是把相同的默认关闭模式扩展到 Equipment 主动业务上报，最小
切片先覆盖 Collection Event 发送入口，再评估报警通知、自动恢复、报警
历史和批量控制。
