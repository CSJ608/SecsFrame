当前报告、报警通知和远程命令切片使用可替换工程 profile、动态
<code>SecsItem</code> 标识，并保留报警与命令结果原始代码，不宣称已经
核对 E30 的生命周期、代码语义或应答枚举。报警目录查询同样是非规范性
工程基线；单报警发送启停也使用显式可替换控制码。在线转换策略默认不注册，
保持既有宽松接受行为。通讯建立策略在 Host 与 Equipment 两侧同样默认
不注册；拒绝不改变既有通讯状态或对端身份，恢复由应用在同一 Selected
会话显式重试，库不启动后台循环。远程命令接受策略也默认不注册；应用可
依据当前通讯/在线状态决定是否执行命令，库不内置未经 E30 核对的状态矩阵。
Collection Event 发送策略沿用相同的默认不注册模式；拒绝发生在动态值
采集和 S6F11 事务之前，应用改变决策后可在同一会话显式重试。
报警通知发送策略同样默认不注册；已注册报警的发送启停检查优先，策略拒绝
发生在 S5F1 事务之前，并可在同一会话显式重试。至此当前 Equipment 主动
业务发送入口的应用状态策略已经闭环。

报警历史/批量控制仍是标准核对后的优先项：最小切片必须先用授权 E30-0526
核对消息条件、数据结构和代码语义，再确定可替换 profile 下的不可变历史
模型、Equipment 快照边界、Host 查询 API、严格向量和真实 TCP 证据；核对
完成前不固化新的默认消息对。

当前仓库没有可用于该核对的授权材料，因此先完成不新增消息映射的 Equipment
运行期命令目录：动态标识精确处理器优先，现有单一处理器作为全局回退，
未知命令保持失败结果。下一可执行优先级是评估命令权限/参数约束如何复用
现有全局接受策略而不重复策略层；自动恢复和调度继续保持后续评估项。
